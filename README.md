# 云端个人新闻定时聚合与大模型解读系统

每天在云端自动抓取公开新闻源，调用 OpenAI 兼容大模型整理为中文要闻解读，并发布为 GitHub Pages 静态页面。

最终访问：

```text
https://<你的 GitHub 用户名>.github.io/<仓库名>/news/latest.html
https://<你的 GitHub 用户名>.github.io/<仓库名>/news/latest.json
https://<你的 GitHub 用户名>.github.io/<仓库名>/news/YYYY-MM-DD.html
https://<你的 GitHub 用户名>.github.io/<仓库名>/news/YYYY-MM-DD.json
```

## 云端架构

```text
GitHub Actions 北京时间每天 08:00 触发
→ RSS / 官方公开源采集
→ 大模型去重、分类、摘要、影响解读
→ 生成 public/news/*.json 和 public/news/*.html
→ GitHub Pages 发布 public/
→ 可选备份到 Supabase
```

## 本地手动运行

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python -m src.main
```

生成文件：

```text
public/news/YYYY-MM-DD.json
public/news/YYYY-MM-DD.html
public/news/latest.json
public/news/latest.html
```

## 新闻源配置

`.env` 或 GitHub Actions Variables 中配置 `NEWS_SOURCES`：

```env
NEWS_SOURCES=[{"name":"新华网时政","region":"domestic","type":"rss","url":"http://www.xinhuanet.com/politics/news_politics.xml","enabled":true},{"name":"BBC World","region":"international","type":"rss","url":"https://feeds.bbci.co.uk/news/world/rss.xml","enabled":true}]
```

字段：

- `name`：来源名称
- `region`：`domestic` 或 `international`
- `type`：`rss` 或 `html`
- `url`：公开新闻源地址
- `enabled`：是否启用

默认优先 RSS；HTML 仅作为备用，并会检查 `robots.txt`。

## 大模型 API

系统使用 OpenAI 兼容接口，可接 OpenAI、OpenRouter、DeepSeek 等。

OpenRouter Free Models 示例：

```env
ENABLE_LLM_ANALYSIS=true
OPENAI_API_KEY=你的 OpenRouter Key
OPENAI_BASE_URL=https://openrouter.ai/api/v1
OPENAI_MODEL=openrouter/free
OPENAI_TIMEOUT=90
```

GitHub Secrets 中配置：

```text
OPENAI_API_KEY
```

GitHub Variables 中配置：

```text
OPENAI_BASE_URL=https://openrouter.ai/api/v1
OPENAI_MODEL=openrouter/free
BASE_URL=https://<你的 GitHub 用户名>.github.io/<仓库名>
```

## GitHub Pages 部署

1. 推送代码到 GitHub 仓库。
2. 打开仓库 `Settings → Pages`。
3. Source 选择 `GitHub Actions`。
4. 打开 `Settings → Secrets and variables → Actions`。
5. 配置 Secrets 和 Variables。
6. 在 `Actions → Daily News Digest` 手动运行一次，或等待每天北京时间 08:00 自动运行。

GitHub Actions cron 使用 UTC：

```yaml
cron: "0 0 * * *"
```

即北京时间 08:00。

## Supabase 备份

可选开启：

```env
ENABLE_SUPABASE_BACKUP=true
SUPABASE_URL=https://xxxx.supabase.co
SUPABASE_SERVICE_ROLE_KEY=你的 service role key
SUPABASE_TABLE_DIGESTS=news_digests
SUPABASE_TABLE_ARTICLES=news_articles
```

GitHub Secrets：

```text
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
```

建议建表 SQL：

```sql
create table if not exists news_digests (
  id bigint generated by default as identity primary key,
  digest_date date not null unique,
  period_from date not null,
  period_to date not null,
  json_payload jsonb not null,
  html_content text,
  generated_at timestamptz not null,
  created_at timestamptz default now()
);

create table if not exists news_articles (
  id bigint generated by default as identity primary key,
  digest_date date not null,
  hash text not null,
  title text not null,
  source text,
  url text not null,
  region text,
  category text,
  published_at timestamptz,
  summary text,
  impact text,
  why_it_matters text,
  confidence numeric,
  raw_payload jsonb,
  created_at timestamptz default now(),
  unique (digest_date, hash)
);
```

安全提醒：`SUPABASE_SERVICE_ROLE_KEY` 只能放在 GitHub Secrets 或服务器环境变量中，不要提交到仓库，不要放进前端页面。

## 合规原则

- 优先 RSS 和官方公开信息源。
- 不绕过反爬、验证码、Cloudflare 或登录限制。
- 不抓取个人敏感信息。
- 所有请求设置 timeout。
- 使用诚实 `User-Agent`。
- 保留来源链接。
- 大模型不得编造新闻。
- 信息不足时明确标注“信息不足，暂不解读”。
